Kanji Grid
==========

Improved/updated version of the [Kanji Grid][0] addon for Anki 2.1.

Differences from the original
-----------------------------

 - Compatible with Anki 26.09+
 - Grouped grids can include kanji missing from the selected deck, shown at the bottom of each group with a distinct style.
 - Remembers the last used deck and grid settings between runs.

[0]: https://ankiweb.net/shared/info/909972618
